1. Rejection of Generic Cloud AI & Pure Regex Systems [Page 1 / 3]

Failure Modes of Generic Cloud AI (GPT-4 / Claude)

  • Probabilistic Hallucination & Numerical Drift: In archival OCR benchmarks, commercial LLMs silently alter critical excavation coordinates and depth strata (empirical test transcribed 1966 as 1656, and 20–40 cm as 20–10 cm). Numeric fidelity is non-negotiable.
  • Antiquities Permit NDAs & Looting Risk: Excavation field reports contain unexcavated findspot GPS coordinates. Sending unredacted data to cloud APIs violates state antiquities permits and exposes vulnerable sites to illicit looting.
  • Prohibitive Latency: Full-page cloud LLM inference takes 15–30s per page, making batch ingestion of 500-page monographs computationally unviable.

Failure Modes of Pure Regex / Traditional Parsers

  • Multi-Clausal Syntactic Collapse: Regular expressions fail catastrophically when a single sentence contains multiple chronological layers (e.g., "pottery recovered in 1968, though Evans (1921) noted similar forms dating to 1450 BCE").
  • Multilingual Archaic Variations: Fails across historical German, French, and Victorian English excavation prose where syntactic structures and abbreviations diverge unpredictably.

2. The Chosen Architecture: Hybrid C++20 + Governed Local Neural Model

+-----------------------------------------------------------------------------------+ | ARCHIVAL INGESTION DUAL-ROUTING PIPELINE | +-----------------------------------------------------------------------------------+ Raw Scan (PDF / TIFF) ---> OCR & Layout Analysis | +---> [Class A: Clean Typography] ---> Native C++ Engine (<1 ms) ---> Deterministic Commit | +---> [Class B: Degraded Archival] ---> Split-Screen UI ---> Human Double-Entry (0% Auto-Fill Pre-fill)
  • Native C++20 Fast Path: Executes deterministically in sub-millisecond time with zero heap allocation per token, extracting measurements, counts, and stratigraphic relationships via mathematical grammar parsers.
  • Governed Local Neural Model: An in-process, 4-bit quantized Qwen 2.5 7B GGUF (~4.4 GB) model, invoked solely for semantic ambiguity resolution. It runs fully offline with zero internet access required.
  • Strict Air-Gap Guarantee: The system opens zero outbound TCP/UDP ports. All UI communication executes through in-memory Win32 WebView2 IPC, ensuring complete compliance with antiquities permit NDAs in remote field excavation camps.

2. Governed Neural Arbitration: How Hallucinations Are Eliminated

The Selection-Only Guardrail Architecture

Unlike consumer chat interfaces, ArchaeoPhD never permits the neural model to generate free-form text:

  • Grammar-Constrained Output: The model receives the verbatim text snippet alongside the pre-extracted C++ candidate list. It is constrained via grammar sampling to output only the index integer of the verified candidate or REJECT. It cannot invent names or dates.
  • The Class B Invariant: "A blank field is infinitely safer than a plausible wrong one." On degraded 19th-century letterpress scans, automated pre-fill is locked out; the researcher transcribes via split-screen verification.

1. Critical Failure Modes & Engineering Mitigations [Page 3 / 3]

  • Where C++ Deterministic Rules Fail: Syntactic parsers cannot resolve unaligned multi-column OCR tables or damaged physical plates where typography is fragmented.
    Mitigation: Flagged deterministically as UNANCHORED_OR_DEGRADED and routed to the human verification queue.
  • Where the Local Neural Model Fails: 3–5s execution latency and 4.4 GB RAM footprint. If unconstrained, it risks plausible confabulations.
    Mitigation: Strict quarantine to multi-candidate arbitration; constrained index decoding prevents free-form generation.
  • Where Dense Semantic Vector Retrieval Fails: High-dimensional embeddings cluster documents using similar theoretical terminology even if their stratigraphy or geographic regions conflict.
    Mitigation: Dual-stage lexical BM25 filtering enforces exact trench identifiers, locus numbers, and site names.

2. Planned Technical Experiments (Doctoral Research Roadmap)

Experiment 1: Local Vision-Language Models (VLMs) on High-Resolution Letterpress Crops

Engineering Goal: Test quantized local VLMs (Qwen2-VL 2B/7B GGUF) directly on segmented typographic plates from 19th-century monographs (e.g., Petrie, Evans). By processing high-resolution bounding crops rather than full pages, we eliminate token collapse and preserve sub-millimeter plate coordinates without cloud data leakage.

Experiment 2: 3D Volumetric Voxel Intersections in the Harris Matrix DAG

Engineering Goal: Bridge trench Structure-from-Motion (SfM) 3D photogrammetric meshes directly into the C++ Tarjan DAG solver. Instead of relying on manual 2D context sheets, the engine will compute 3D volumetric intersections between stratigraphic units to mathematically detect physical overlap violations.

Experiment 3: Native C++ Bayesian Sequential Calibration Engine (OxCal-in-C++)

Engineering Goal: Embed an in-process Markov Chain Monte Carlo (MCMC) Bayesian sampler directly into the native C++ binary. This fuses prior stratigraphic DAG topological constraints with posterior IntCal20 continuous radiocarbon probability envelopes on-device, replacing external commercial legacy software.

Summary for the Doctoral Advisory Committee: ArchaeoPhD pairs deterministic C++ engines for sub-millisecond mathematical precision and zero numerical drift with a governed, offline neural model for semantic nuance. The resulting architecture delivers a fully air-gapped, verifiable computational platform engineered for doctoral-level research.
